# 问题 #23：VAD 合并失败清空整棵树

## 1. 问题编号

`23`

## 2. 问题位置

- 文件路径：`src/mm/vad.zig`
- 函数/模块：`coalesceAdjacent`
- 行号或代码片段：原实现插入失败时直接 `clear()`。

## 3. 问题描述

合并重建过程中若插入失败，整棵 VAD 树被清空，丢失与当前操作无关的节点。

## 4. 复现路径

在重建插入失败（如资源耗尽）时触发 `coalesceAdjacent()`。

## 5. 影响范围

可导致整个地址空间元数据丢失、后续查询和缺页处理异常。

## 6. 严重程度

High

## 7. 可能原因

事务性重建没有保存原树快照，也没有失败恢复路径。

## 8. 权威参考依据

- Windows NT/ReactOS 内存管理语义：VAD 更新失败应保持原状态。
- 本次修复来自源码审计与测试，未将 REA 二进制分析结论作为修复依据。

## 9. 建议修复方案

已在重建前保存原中序快照；插入失败时清空临时树并按快照恢复，再返回。

## 10. 验证方法

新增 `vad coalesce preserves mixed attributes` 测试，验证属性不同的相邻节点不会被错误合并或丢失。

## 11. 状态

Fixed

## 12. 修复验证记录

- `zig build test` 通过。
- `zig build -Darch=x86_64`、`aarch64`、`riscv64`、`loongarch64` 通过。
- REA 与 Windows 7 镜像逐函数对照：未执行。
