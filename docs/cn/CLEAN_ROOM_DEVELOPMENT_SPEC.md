# ZirconOS Aero Clean Room开发规范
## 版权合规核心原则
本项目所有开发严格遵循Clean Room开发规范，100%规避微软版权风险，所有代码仅基于以下合法来源：
1. 微软公开的官方技术文档（包括MSDN文档、Windows Driver Kit公开文档、公开的NT内核技术规范）
2. 微软公开发布的可授权使用的Windows Research Kernel (WRK) 代码，仅使用其明确允许复用的部分
3. 已通过版权验证的开源兼容层项目（如ReactOS、Wine等）的MIT/BSD/GPL兼容许可证代码
4. 项目团队自主开发的原创代码

## 开发流程规范
### 1. 代码来源追溯要求
- 所有导入的第三方代码必须保留完整的许可证声明和来源追溯信息
- 所有新开发的代码必须仅基于公开文档描述的功能语义实现，禁止参考任何微软未授权的专有代码
- 禁止任何对Windows系统二进制文件的反编译、逆向工程得到的代码直接进入代码库
### 2. 版权审核机制
- 所有提交的代码必须通过自动版权扫描+人工审核双校验
- 每季度开展全项目版权审计，排查可能的版权风险
- 建立版权问题响应机制，发现风险代码24小时内完成替换或移除
### 3. 开发隔离要求
- 开发人员不得接触任何微软未授权的Windows内核源代码
- 功能实现仅基于公开文档的接口定义、行为语义描述进行独立实现
- 兼容性测试仅使用微软公开允许分发的测试工具和合法获取的Windows应用程序

## 合规承诺
本项目所有代码均严格遵循以上规范，如存在任何版权问题，项目团队将立即进行整改。
